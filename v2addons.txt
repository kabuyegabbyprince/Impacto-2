# IMPACTO V2 — System Architecture, Subscriptions & Roadmap Specifications

---

## 1. Subscription Tiers & Trial Lifecycle Matrix

### Tier Specifications
- **Free Forever Plan**:
  - Member Limit: Up to 30 active members
  - Core Features: Member Directory, Roles, Basic Announcements, Standard Chat
  - Storage Limit: 100 MB local media storage
  - Lockdown Rules: If member count or storage exceeds limits, excess records enter read-only mode safely without data deletion.
- **Growth Plan (Default Trial)**:
  - Member Limit: Up to 250 members
  - Features: QR Code Event Attendance, Member Dues & Custom Charges, Basic Financial Ledger, Excel Attendance Export, DocumentOffice Suite
  - Storage Limit: 5 GB cloud storage
- **Pro Plan**:
  - Member Limit: Unlimited members
  - Features: Automated Certificate Generation, Asset & Inventory Tracker, Mobile Money Live Gateway, Public Marketplace, Advanced Ledger Reports
  - Storage: Unlimited cloud storage for all files, media, receipts, and attachments
- **Enterprise Plan**:
  - Member Limit: Unlimited members across multiple branches
  - Features: Multi-Branch Federation, Granular RBAC Permissions, Identity Document Verification Hub, Governance Quorum Validation, Full Historical Audit Trail, Dedicated Account Manager

### Trial & Grace Period Mechanics
- **30-Day Growth Trial**: Every newly registered organization automatically receives a 30-day trial on the Growth Plan.
- **3-Day Grace Period**: When the 30-day trial concludes, a 3-day grace period is granted before plan enforcement takes effect.
- **Data Preservation & Resumption**: Transitioning to Free preserves all records safely. Upgrading unlocks all features and historical data immediately.

---

## 2. Feature Packages & À La Carte Marketplace

### Curated Feature Packages
- **Governance Pack**: Quorum Validation + Document E-Signatures + Version Acknowledgement + Audit Trail
- **Field Operations Pack**: QR Code Attendance + Asset Tracker + Offline PWA Sync Queue
- **Fintech & Payments Pack**: Mobile Money Push-to-Pay API + Automated Dues Schedules + Excel Financial Export

### Marketplace Rules
- **Package Duration**: A-la-carte packages purchased or claimed on the Free Plan remain active for 30 days.
- **Dynamic Pricing**: Package valuations are dynamically computed from composite feature prices set by system administrators.
- **Thematic Categorization**: Features are categorized under Finance, Governance, Operations, and Communications.

---

## 3. Storage & Storage Buckets (Supabase Storage)

IMPACTO utilizes 4 primary Supabase storage buckets:
- **`avatars`** (Public): User profile images, organization brand logos, cover banners, and marketplace item imagery.
- **`documents`** (Public): Identity verification documents, official meeting minutes, certificates, and compliance policies.
- **`chat-attachments`** (Public): Live chat images, outreach media, and recorded voice notes.
- **`impacto-files`** (Public): System asset fallbacks and financial receipts.

---

## 4. Mobile Money Gateway & Payment Webhooks

### Deposit & Verification Workflow
1. **Initiation**: User or member submits a contribution with amount, currency (`RWF`), and payer mobile number (MTN / Airtel).
2. **Review & Audit Queue**: Transactions appear in the cooperative accounting queue with uploaded receipt/SMS reference codes.
3. **Webhook Callback Receiver**: The backend endpoint `/api/payments/webhook` and `/api/payments/momo/callback` processes inbound push notifications and status updates.
