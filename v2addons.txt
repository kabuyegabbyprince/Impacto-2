# IMPACTO V2 — Future Roadmap, Subscription & AI Specifications

## 🤖 1. AI Feature Integration: "Impacto AI Assistant"
- **Purpose**: A lightweight, practical AI companion embedded directly into the platform workflow.
- **Key Capabilities**:
  - **Smart Meeting Summaries**: Automatically parses meeting notes and attendance to generate concise executive decisions and action items.
  - **Ledger & Expense Insights**: Detects anomalous transaction spikes or flags missing receipt references in financial books.
  - **Communication Drafter**: Instantly generates professional announcements, member thank-yous, and dues reminder messages using variable templates.

---

## ⏳ 2. Subscription Lifecycle & Trial Mechanics
- **Default Trial**: New organizations start automatically on the **Growth Plan** for a 30-day free trial.
- **Grace Period**: Upon trial expiration, organizations receive a strict **3-day Grace Period** to select a paid subscription or transition to the Free Forever plan.
- **Free Forever Plan Limitations**:
  - **Member Cap**: Strictly limited to a maximum of **30 active members**.
  - **Data Lockdown**: Excess member records, advanced ledger reports, and secure document vaults beyond Free limits become locked (read-only / inaccessible).
  - **Resumption**: When the organization upgrades to a paid plan, all locked data and features instantly resume full functionality without data loss.

## 📦 4. Feature Packages & À La Carte Marketplace
- **Feature Grouping (Packages)**: 
  - Features can be grouped into curated packages (2 to 4 complementary features per package) drawn from higher-tier plans.
  - *Example Packages*:
    - **Governance Pack** (Quorum Validation + Document E-Signatures + Audit Trail)
    - **Field Ops Pack** (QR Attendance + Asset Tracker + Offline Sync Queue)
    - **Fintech Pack** (MTN/Airtel Live APIs + Automated Dues + Excel Export)
- **Package Usage Rules**:
  - Organizations on lower plans can purchase or claim individual packages to use them in their current plan until the package expires.
  - If a package is claimed or assigned on the Free Plan, it **expires automatically after 30 days**.
- **Marketplace & Admin Pricing**:
  - **Admin Pricing Control**: Platform and organization administrators can set custom pricing for individual features in the system marketplace.
  - **Feature Themes (Default)**: Features are categorized by themes (Finance, Governance, Operations, Communication).
  - **Package Valuation**: Package pricing and value are dynamically calculated based on the combined value of the individual features included within them.

## 💳 8. pawaPay.io Push-to-Pay Integration Plan
- **Overview**: Standardised API integration for MTN MoMo and Airtel Money across Sub-Saharan Africa (`https://api.sandbox.pawapay.io` vs `https://api.pawapay.io`).
- **Core Deposit Workflow**:
  1. Backend generates a `depositId` (UUIDv4) and stores it locally as `PENDING` before calling pawaPay.
  2. Call `POST /v2/deposits` with amount, currency, payer phone number, and provider (`MTN_MOMO_RWA`, etc.).
  3. Receive synchronous `ACCEPTED` status; customer receives PIN prompt on their mobile device.
  4. Receive final webhook callback (`COMPLETED` or `FAILED`).
- **Three-Layer Reliability Approach**:
  - **Layer 1 (Webhooks)**: Secure endpoint (`POST /webhooks/pawapay/deposit`) with signature verification and idempotent status updates.
  - **Layer 2 (Status Polling / Reconciliation)**: Scheduled job checking transactions pending > 15 minutes via `GET /v2/deposits/{depositId}`.
  - **Layer 3 (pawaPay Internal Reconciliation)**: Automatic resolution for `IN_RECONCILIATION` states.
- **Dynamic UX & Validation**:
  - Dynamic provider picker via `GET /v2/active-conf`.
  - Phone number sanitisation and network auto-detection via `POST /v2/predict-provider`.
  - Decimal and min/max amount validation per provider limits before submission.
  - Defensive status handling (`NEEDS_ATTENTION` escalation path).
